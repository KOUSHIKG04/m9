## Unslop audit and direction

Polish mode: the user-pinned PDF already supplies the identity, layout, typography and palette. Preserve those decisions. The audit found a vague hero action, unneeded continuous radial motion, a catch-all shared-button transition, and contact placeholders that did not use the real agency integration.

- Product: MOTIVE 9 connects prospective clients with freelance design and website development.
- Character: bold, direct, collaborative.
- World: the supplied graphic-design portfolio, in yellow, charcoal and white.
- Moments: reference-led oversized hero and geometric portfolio; an illustrative website-build preview inside its owning service disclosure.
- Signature: radial geometry, used in the existing brand language.

Changes: clearer booking action, static hero linework, explicit button transition properties, the real email and booking destination, and a real enquiry form using the existing endpoint. Existing reference typography, section labels and composition take precedence over general-purpose skill styling defaults.

## Stageshow plan

A still product shot inside the expanded Website Development service. One browser window with a legible website composition; no overlay competing with its headline, not interactive UI or a claimed client project. The wide version bleeds past the right and lower frame; compact composition removes surplus navigation and keeps the headline and action readable. The existing Motive9 product-showcase runtime and static-card framing example provide the starting references. A still avoids decorative playback and gives reduced-motion users the same information.
